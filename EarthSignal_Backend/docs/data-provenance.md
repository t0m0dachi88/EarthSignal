# Data provenance

The bundled annual anomaly dataset is identified in its NetCDF attributes as NASA GLDAS Noah V2.1, period 2003-01 through 2023-12 baseline, annualized into 21 year records. Six variables are included. Cell-level ML features and discovery outputs were exported from the EarthSignal Colab pipeline.

The three additional dataset products in the catalog are catalog-only and are not represented as downloaded observations.
